# 한글 문서 문체 규칙

공문서·보고서·계획서 본문을 쓸 때 적용한다. 형식이 맞아도 문체가 어긋나면 반려되거나 AI가 쓴 티가 난다.

## 1. 개조식이 기본이다

공문서와 계획서 본문은 완결형 문장이 아니라 명사형·서술형 어미로 끊는다.

- ○ `2026학년도 학급 운영 계획을 아래와 같이 수립함.`
- ✕ `2026학년도 학급 운영 계획을 아래와 같이 수립하였습니다.`

어미는 `~함`, `~임`, `~할 것`, `~예정`. 다만 **안내문·가정통신문처럼 읽는 사람이 일반인이면 경어체 완결문**을 쓴다. 문서 종류를 먼저 판단한다.

## 2. 기호 체계

항목을 나눌 때 순서를 지킨다.

```
□ (16pt)  대항목
  ○ (15pt)  중항목
    ― (15pt)  소항목
      ※ (13pt)  참고·유의
```

번호를 매길 때는 `1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮` 순서다. 단계를 건너뛰지 않는다.

## 3. 날짜·숫자

- 날짜: `2026. 3. 2.` — 점 뒤에 한 칸, 마지막에도 점
- 기간: `2026. 3. 2. ~ 2027. 2. 28.`
- 금액: `1,234,000원`
- 시각: `14:00` 또는 `오후 2시`

## 4. AI 티를 없애는 법

아래 표현이 들어가면 지운다. **지운 자리에는 숫자·고유명사·실제 사례를 넣는다.** 빈 수식어를 다른 수식어로 바꾸는 건 소용없다.

### 쓰지 않는 표현

| 유형 | 예 |
|---|---|
| 공허한 수식어 단독 | 다양한, 체계적인, 효과적인, 종합적인, 지속적인 |
| 대구 표현 | "단순한 X가 아니라 Y이다" |
| 3개 병렬 강박 | 근거 없이 항상 세 가지로 나열 |
| 서술어 회피 | "자리매김", "제고", "도모" |
| 기대·당위로만 끝내기 | "~할 것으로 기대된다", "~이 요구된다"로 마무리 |
| 미들닷 | `생성·편집` → `생성, 편집` |
| 구어체 축약 | "이걸로" → "이것으로", "근데" → "그런데" |
| 테이크어웨이 화법 | "얻어갑니다", "만들어 갑니다" |
| 과잉 프레이밍 제목 | "오늘의 약속" → "목차", "순서" |

### 고쳐 쓰기

- ✕ `다양한 활동을 통해 학생들의 역량을 체계적으로 신장시키고자 함.`
- ○ `주 1회 토의 수업과 월 1회 프로젝트 발표로 말하기 능력을 기름.`

- ✕ `단순한 지식 전달이 아니라 삶과 연결되는 배움을 지향함.`
- ○ `교과서 사례를 학교 급식 잔반 문제로 바꿔 다룸.`

### 예고는 구체적으로

막연한 복선을 깔지 않는다.

- ✕ `이 부분은 뒤에서 자세히 다루겠습니다.`
- ○ `구체적인 평가 기준은 3장에서 다룹니다.`

## 5. 문장 길이

한 문장은 35~45자 안에서 끊는다. 두 가지 내용이 접속사로 이어지면 나눈다. 수식어가 세 개 이상 붙은 명사구는 풀어 쓴다.

## 6. 완성 후 점검

본문을 다 쓰면 아래를 훑는다.

1. "다양한", "체계적", "효과적"이 수식어 단독으로 남아 있는가
2. 마지막 문단이 기대·당위로만 끝나는가
3. 미들닷(·)이 남아 있는가
4. 개조식 문서인데 "~습니다"가 섞였는가
5. 숫자로 쓸 수 있는데 "많은", "여러"로 뭉뚱그린 곳이 있는가
